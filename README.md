# Instruções para rodar o projeto

## Requisitos
- **Node.js**
- **npm**

## Passos para execução

1. **Instale as dependências**:
   - Execute o comando:
     ```bash
     npm install
     ```

4. **Rodando o projeto**:
   - Para iniciar o servidor de desenvolvimento, execute:
     ```bash
     npm start
     ```
   - O projeto estará disponível em `http://localhost:3000`.
